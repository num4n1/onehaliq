# 1HALIQ Shipping & Logistics Site

Create a simple, polished responsive website for 1HALIQ Shipping & Logistics. Use the attached logo prominently in the header and brand it throughout using its navy/royal blue, white, and subtle gray palette; set the logo as the browser tab favicon. Build a clear one-page marketing site with hero, shipping services (air, ocean, road), why choose us, shipment tracking CTA/form (demo only), about/trust section, contact form, and footer. Use appropriate shipping imagery/icons and the logo tagline: “Connecting Worlds. Delivering Trust.”
